# Design lineage: Project-Walrus, Project-Apis, Project-Haar

Scope: Project-Walrus, Project-Apis, Project-Haar (with Project-Walrus.backup and Project-Haar.backup for history only). Read-only: nothing in any repository was edited. Paths are relative to the workspace `/home/awickert/Dropbox/NorthernWidget/github`.

Common finding across all three: every schematic uses Bobby Schulz's house Eagle library `bschulz`, which itself contains devicesets copied from SparkFun's CC BY-SA 4.0 Eagle libraries (SparkFun `PROD_ID` attributes and verbatim SparkFun description text survive inside it). That is the SparkFun link each design carries even where no `SparkFun-*` library appears by name.

VERIFIED (text) / LIKELY (that the copy came from SparkFun's libraries rather than a SparkFun board). `bschulz` MOSFET-NCH deviceset (`TPDH-Walrus_HardMount.sch:6868`) has description "N-channel MOSFETs ... SparkFun Products: SparkFun OpenScale, SparkFun Digital Sandbox, SparkFun Monster Moto Shield, SparkFun MOSFET Power Controller" (lines 6871-6875) and SparkFun PROD_IDs TRANS-09984, -11151, -10060, -12437, -12988, -08089 (6889-6971); package TO220V "N-Channel MOSFET SparkFun SKU: COM-10213" (line 229). `bschulz` OSHW-LOGO-M footprint (`TPDH-Walrus_HardMount.sch:2451`) has `urn:adsk.eagle:footprint:37012/1 locally_modified="yes"`; the same URN belongs to the SparkFun-Aesthetics library in `ALog-BottleLogger/ALog-BottleLogger.brd:3266`.

6. **ALog BottleLogger (via TP-DownHole)**: grandparent for parts/inventory. LIKELY (outside my repos, recorded for the binder). TP-DownHole commits `30a57ec` "Same parts as ALog BottleLogger: easier inventory" and `ebae734` "Eagle .gitignore from ALog-BottleLogger" (both 2017-01-26).

README:186-187 directs users to SpenceKonde ATTinyCore, ATtiny1634; README:165 Arduino as ISP, README:167 Adafruit USBtinyISP. Adafruit/SparkFun links in README:91-107 are assembly tutorials (stencil, reflow), not design sources.

Internal variants (same repo): Hardware_LargePTH/TPDH-Walrus (legacy, I2C + full-duplex RS-485), TPDH-Walrus_4pinPTH, Hardware_HardMount (README:65-66).
